Tangent Space is the selected name. The launch package's current product intent gives conversation/shared space priority, with optional goals and summaries backed by full history. Older task-completion examples are examples of one possible use, not general platform behavior.

The HTML was created as a fragment for an inline host. It can be inspected as source or opened in a browser, but its icon rendering may depend on the original host's Lucide global. It has not been revalidated as a standalone application in this packaging pass. Rebuild or replace it freely.

Research links are references to third-party material. Third-party code and dependencies have not been vendored into this package. Evaluate current APIs, compatibility, and applicable licenses before reuse.
