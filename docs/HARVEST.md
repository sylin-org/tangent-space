# Harvest map
This is the map [ADR 0014 §3](adr/0014-tangent-beside-your-site.md) requires: every unit of the proof of concept under `poc/` with a verdict, consolidated from seven audits read against [BRIEF](BRIEF.md) on 28 October 2026.
Paths: every repository path is prefixed `poc/` (the tree moves there, tagged `poc/2026-10-28`); `docs/adr/*` and `docs/BRIEF.md` stay at the root; `.local/` is gitignored and unprefixed. `file:line` citations are the auditors', re-prefixed.
**TRANSPLANT** = works, fits the brief, moves nearly as-is (renames allowed). **HARVEST** = the idea and its edge cases survive, the code is rewritten. **DROP** = not in the brief or superseded.
