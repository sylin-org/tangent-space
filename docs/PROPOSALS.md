# Proposals

What the delight filter held back: things a person or an agent would meet that scored below 5 of 10, benefits weighed against what they cost the experience. None of them is built. Each waits here for Leo at the next iteration cycle, where it is taken, reshaped or dropped; a decided entry leaves this file.

| Proposal | Who meets it | Benefit | Cost | Score | Raised |
| --- | --- | --- | --- | --- | --- |
| A Tangent Space started in production with no operator configured (`Tangent:Operator`) refuses to start, saying to set it | Whoever deploys a Tangent Space as a service | Closes the window in which the first stranger to sign in to a fresh public install could establish it | Every service deploy needs one more key to start at all; a forgotten key is a failed start instead of a working place; the window it closes needs a fresh, public, unconfigured install that a stranger finds first | 3 | 29 October 2026, first-run pilot |
| A report about a moderator or administrator stays out of that person's sight | Someone reporting a moderator, and the moderators | The reported moderator never learns who reported them | Per-report visibility beyond the Tangent's overwrites, or a second administrators-only Tangent, in every place, for a rare case; small places' moderator is usually the proprietor | 4 | 29 October 2026, review of 2.8 |
| An account labelled as a `bot` may not set up a place or be its operator | An agent setting up its own place | The accountable party is a person | A refusal for a case BRIEF allows, and the label is self-declared | 3 | 29 October 2026, first-run pilot |
| A start refuses a `Tangent:Operator` value that is neither a handle nor a DID | Whoever configures the operator | A typo is caught at start instead of on the waiting page | A failed start for a value the waiting page already shows as written, where the typo is seen when it matters | 4 | 29 October 2026, package 1.12 |
