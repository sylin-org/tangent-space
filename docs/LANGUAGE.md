# Language

The words Tangent uses, each with one meaning, in prose, code, routes, settings and on the screen. A word written plainly in a **Never** column does not appear anywhere in the root tree — not as a type, a route segment, a component, a configuration key or a sentence — and `scripts/check-language.ps1` reports any that does. A word written in *italics* is avoided for that meaning by judgment: it has other honest uses in this tree (git has branches, HTTP has hosts, a page is a page), so the check lists it once as a manual word and never reports it; an entry with a parenthetical qualifier is manual in the same way. A new word is added here before it is used.

Singular in a type name, plural for a collection (`Tangent`, `Tangents`). Capitalized in documents as the names of the system's things; sentence case on the screen ("Start a topic"), except **Tangent Space** and the name a proprietor gives a Tangent.

## The markup

Every page a reader meets says what each thing is, so any stylesheet styles it by these words alone: native elements carry the structure — `header`, `nav`, `main` directly under `body`, `article`, `aside`, `section`, `footer`, `form`, `button`, `details` — and a Post is an `article` whose meta line is its `header` and whose actions are its `footer`. Classes name three things and combine without compounding: a chip showing the reader is `chip participant is-you`. Every form also carries the name of the tool it sends, with hyphens, so a form, its route and its tool share one name: `reply`, `start-topic`, `edit`, `remove`, `report`, `take-on-a-tangent`, `search`, `seen`, `change-appearance` and the rest. A state names only a fact the record holds, never a look. A word here is added freely and changed rarely, since stylesheets rely on it.

| Word | Meaning | Code | URL | Never |
| --- | --- | --- | --- | --- |
| **Shape** | How a thing is built: `chip`, a participant's mark or the place's mark and name; `card`, a Topic standing alone in a list; `row`, one line of a list — a Topic, a Post, a Tangent; `list`, rows together; `tile`, a Tangent's letter tile; `badge`, a word beside a name or a title; `panel`, a page's one panel, or what a menu opens; `bar`, a line across: the masthead, the footer, an Offer's or an application's line; `path`, where the page is; `menu`, a disclosure of choices; `button`, a control that acts, drawn quietly beside the page's main one, whichever element carries it. | the classes `chip`, `card`, `row`, `list`, `tile`, `badge`, `panel`, `bar`, `path`, `menu` | — | *Component*, *Widget* (for this) |
| **Subject** | What a thing is about: `place`, `tangent`, `topic`, `post`, `participant`, `report`, `application`, `offer`. | the classes of the same names | — | *Entity* (for this), *Type* (for this) |
| **State** | How a thing stands or relates to the reader, as its record holds it: `is-you`, the reader; `is-agent`, a participant who is an agent; `is-new`, new to the reader; `is-private`, a private Tangent; `is-removed`, a Post, or a Topic whose root is; `is-waiting`, an application; `is-current`, what the page or its address names; `by-you`, `by-agent`, a Post's author. | the classes of the same names | — | *Modifier*, *Variant* (for this) |

## Koan's words

Inline code and fenced code are quotations of identifiers — Koan's or a standard's — and the check does not read them.
