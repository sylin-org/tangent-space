# S01 — native integration path proved

Observed 9 September 2026. This is the historical opening capability receipt. The [application evidence](../../docs/evidence/README.md) records the completed downstream integration.

## Reproduce

Start the [pinned test network](../spaces-network/README.md) and [native client](../AtprotoClientProbe/README.md), then run from the repository root:

```powershell
./probes/scripts/prove-s01.ps1
```

The [redacted receipt](s01-native.json) records 15 passing checks: real OAuth for five accounts on two PDSes; callback replay, issuer and state rejection; authority-scoped Space creation; a participant-owned write on PDS2; an authorized participant on PDS1 reading the same source URI/CID; outsider denial; refusal of room access under plain sign-in scope; real token refresh; and transport of the two-root Spaces CAR with verification explicitly unimplemented.

The independent [Koan receipt](../KoanHostProbe/evidence/2026-09-09/receipt.json) records 13 passing host, SQLite, restart and corrective-configuration checks. The [native lifecycle receipt](../AtprotoClientProbe/evidence/native-lifecycle-2026-09-09.json) records a real process restart and session restoration/refresh. It predates the disposable network restart, so its account DIDs intentionally differ from the combined receipt.

## Findings that affect implementation

1. **Use native .NET OAuth and Spaces transport.** CarpaNet supplies PKCE, PAR, DPoP, token exchange and refresh. Integration guards add issuer/state/subject-to-resolved-PDS consistency. No TypeScript token-owning helper is needed for these operations.
2. **Generic AT authentication is enough.** Plain `atproto` scope signs in without email or Bluesky profile calls. It cannot acquire room delegation. Participants receive separate narrow room grants; the authority receives a separate management grant.
3. **Local declarations resolve and verify.** The official resolver verifies the signed CAR/MST containing local-only schemas. A CommonJS import bug initially blocked this path; the recorded one-line correction restores it. [Resolution evidence](../spaces-network/evidence/lexicon-resolution-2026-09-09.json)
4. **Custom records need application validation.** This PDS accepts unknown custom records by default, while `validate:true` rejects even a valid dynamically published schema. The official schema validator accepts a valid message and rejects a malformed one when supplied the resolved schema. Tangent must validate both writes and ingestion. [Validation evidence](../spaces-network/evidence/record-validation-2026-09-09.json)
5. **Admission removal has a credential window.** It blocks new credentials immediately; an existing credential still reads successfully. The observed issued lifetime is 7200 seconds. Tangent must enforce current policy on every application read; it cannot promise immediate revocation of an already-issued protocol credential. [Boundary evidence](../spaces-network/evidence/baseline-post-interop-2026-09-09.json)
6. **Spaces repository verification is a real SDK gap.** The SDK's public v3 MST parser reports version zero and zero records for the new format. Successful HTTP or CAR parsing is not an integrity proof. The next bounded experiment is an in-process verifier using established crypto/hash implementations and official fixtures. Until it passes, do not claim verified synchronization. A separate runtime remains a fallback requiring an explicit tradeoff.

This closes S01's capability investigation, including its required identification of gaps. It does not close S02–S07. The HTTP consent driver is not a browser sign-in test; cookie correlation, Koan lifecycle, domain governance, unattended credentials, source acceptance and full recovery still require their own evidence.

Later in the same implementation, the native Spaces verifier passed official oracle cases and actual legacy DID key/CAR cases, then supported the real application conversation and recovery proofs. No token-owning protocol helper was added to the application. See the current evidence index above; the initial probe's unverified transport claim remains intentionally unchanged.
