Create:

Update an identity: change its handle or display name inline, then press Save. Deleting refuses while enrollments exist unless you confirm a cascade (their sessions are forgotten too).

Atmosphere sign-in

Sign an identity in to its atproto account (e.g. Bluesky) with an app password — create one in the account's privacy settings; never use the account's main password. The connector exchanges it for a PDS session kept in connector state (cookie-jar posture); the password itself is used for the one sign-in request and is never stored, logged or echoed. Sign In again to replace an expired session; Log Out (in the table above) clears the binding and leaves server enrollment sessions untouched.

Client allowlist

An MCP client that calls SelectCompanion or Connect without naming an identity resolves exactly the identity recorded for its clientInfo.name. A rule without an identity — like an unlisted client — resolves nothing. The allowlist is a guard against silent wrong-identity action on this machine, not an authentication boundary.
